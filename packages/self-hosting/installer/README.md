The canonical unattended installer is [modules/installer.nix](../modules/installer.nix), built as `.#installer` from the same flake as `.#node`. It runs the stable-path [disk guard](../scripts/disk-guard.py), then the node's disko closure and offline `nixos-install`. It refuses incomplete SSH/secret settings and never selects a disk by enumeration. Booting it is destructive after the ten-second abort countdown; explicit human approval is required.
