The shared installer is [modules/installer.nix](../modules/installer.nix) plus [modules/installer-iso.nix](../modules/installer-iso.nix). The `Fleet` workflow builds `.#installer` and uploads `fleet-installer.iso`. `just fetch-iso` downloads that artifact. `just build-iso` still builds it locally when a Linux builder is available.

The ISO contains the `ci`, `web`, `cache`, and `netboot` closures and a manifest at `/fleet-install-manifest` (the live system reads `/iso/fleet-install-manifest`). It does not contain `ci-gpu` or an age key. The boot menu defaults to `ci` after 5 seconds. The other entries pass `fleet.role=web`, `fleet.role=cache`, or `fleet.role=netboot`. `fleet-auto` then wipes the one internal disk `select-disk` chose and installs that closure. SSH uses [settings/installer.nix](../settings/installer.nix) and is optional. One USB boots every role on the image, from Windows, Linux, or an empty disk. The netboot ramdisk is the same installer without those closures, and `fleet-auto` exits without wiping when the manifest is absent. TODO: the netboot host does not serve this ISO. The netboot role tells other clients to boot local disk unless `reinstall.nodes` or `reinstall.roles` flags them.

Booting the installer ISO wipes the internal disk. The netboot ramdisk does not. The live image has no fleet hostname.
