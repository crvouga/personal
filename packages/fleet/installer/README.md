The shared installer is [modules/installer.nix](../modules/installer.nix) plus [modules/installer-iso.nix](../modules/installer-iso.nix). The `Fleet` workflow builds `.#installer` and uploads `fleet-installer.iso`. `just fetch-iso` downloads that artifact. `just build-iso` still builds it locally when a Linux builder is available.

The ISO contains the `ci`, `web`, `cache`, and `netboot` closures and a manifest at `/fleet-install-manifest`. It does not contain `ci-gpu` or an age key. The console logs in as `nixos` and runs `fleet-install`. That command partitions the disk only after the printed path is typed. SSH uses [settings/installer.nix](../settings/installer.nix) and is optional. One USB boots every role on the image. The netboot ramdisk is the same installer without those closures.
